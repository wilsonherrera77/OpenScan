❌ PROBLEMA ANTERIOR:
═════════════════════════════════════════════════════════════════════════

Al intentar instalar LumaraScan_v4.0.3_STABLE.apk aparecía:

  "No se instaló la app porque parece que el paquete no es válido."


🔍 CAUSA RAÍZ:
═════════════════════════════════════════════════════════════════════════

1. El APK v4.0.3 inicial fue compilado SIN firma de release
   → Android usa firma de debug por defecto

2. El APK v4.0.2 anterior estaba firmado con firma release
   → Android no permite actualizar con firma diferente

3. ProGuard estaba activado pero causaba problemas
   → Algunas clases necesarias se eliminaban


✅ SOLUCIÓN IMPLEMENTADA:
═════════════════════════════════════════════════════════════════════════

1. Creado keystore permanente para Lumara Scan ✅
   - Archivo: android/lumara-release-key.jks
   - Alias: lumara-key
   - Validez: 10,000 días (~27 años)
   - Este keystore se usará en TODAS las versiones futuras

2. Configurado archivo key.properties ✅
   - Define credenciales del keystore
   - Build.gradle lo lee automáticamente

3. Desactivado ProGuard/minify temporalmente ✅
   - minifyEnabled: false
   - shrinkResources: false
   - Evita problemas de clases eliminadas incorrectamente

4. Recompilado APK con firma correcta ✅
   - Ahora usa firma release consistente
   - Compatible con instalaciones futuras
