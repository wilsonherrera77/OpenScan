# 📋 Guía Rápida de Campo

**Lumara Indígenas** - Referencia rápida para operadores de campo

---

## ⚡ Inicio Rápido

### 1. Login
```
Usuario: [tu_usuario]
Contraseña: [tu_contraseña]
```

### 2. Digitalizar Documento (5 pasos)

```
1. Seleccionar Persona → Buscar → Seleccionar
2. Tomar Foto → Enfocar → Capturar
3. Verificar Calidad → Si es buena, continuar
4. Tipo de Documento → Seleccionar de lista
5. Subir → Esperar confirmación
```

---

## 📸 Consejos para Buenas Fotos

✅ **HACER:**
- Usar luz natural
- Documento completo en cuadro
- Foto nítida (sin mover el celular)
- Documento plano

❌ **EVITAR:**
- Sombras sobre el documento
- Reflejos o brillos
- Fotos borrosas
- Cortar esquinas del documento

---

## 📶 Trabajar Sin Internet

### Modo Offline Activado
- ✅ Puedes seguir trabajando normalmente
- 📥 Documentos se guardan en el celular
- 🔄 Se suben automáticamente cuando hay WiFi/datos

### Ver Pendientes
```
Menú → Estado de Sincronización
```

### Sincronizar Manualmente
```
Menú → Sincronizar Ahora
```

## 🔋 Optimización de Batería

- Cierra apps que no uses
- Baja brillo de pantalla
- Desactiva WiFi/Bluetooth si no los usas
- Lleva cargador portátil

---

## ⚠️ Problemas Comunes

| Problema | Solución Rápida |
|----------|----------------|
| App lenta | Limpia caché en Configuración |
| Foto borrosa | Tómala de nuevo con más luz |
| No sube | Verifica conexión a internet |
| Sin espacio | Elimina archivos del celular |
| Cámara no abre | Reinicia la app |
