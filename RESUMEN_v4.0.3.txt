❓ SI AÚN NO SINCRONIZA:
═════════════════════════════════════════════════════════════════════════

1. Verificar conexión WiFi:
   - Celular conectado a WiFi (NO datos móviles)
   - Misma WiFi que el PC
   - IP del servidor correcta

2. Verificar IP del servidor desde PC:
   ip addr

   Buscar la interfaz WiFi y anotar la IP
   Debe ser 192.168.40.17 (o la IP que veas)

3. Usar diagnóstico de red:
   - Tocar network_check en la app
   - Leer mensaje de error detallado
   - Compartir captura si persiste el problema

4. Verificar que Tejido está corriendo:
   curl http://192.168.40.17:8001

   Debe responder (HTTP 200 o 302)
