  1. PROBLEMA REPORTADO
═══════════════════════════════════════════════════════════════════════

Error al iniciar sesión:
  "Error: Invalid argument(s): HTTPS required in production. Got: http"

Causa:
  La app bloqueaba HTTP incluso para servidores en red local (192.168.x.x)

Impacto:
  Usuario NO podía iniciar sesión en la app
  → Aplicación inutilizable


═══════════════════════════════════════════════════════════════════════
  2. SOLUCIÓN IMPLEMENTADA
═══════════════════════════════════════════════════════════════════════

Archivo modificado:
  lib/data/datasources/paperless_api_client.dart (líneas 127-157)

Cambio:
  ANTES: Bloqueaba TODO HTTP en modo producción
  AHORA: Permite HTTP SOLO para IPs de red local

IPs permitidas con HTTP:
  ✅ localhost / 127.0.0.1
  ✅ 10.x.x.x (Clase A privada)
  ✅ 172.16-31.x.x (Clase B privada)
  ✅ 192.168.x.x (Clase C privada) ← CASO DEL USUARIO

IPs que REQUIEREN HTTPS:
  ❌ Cualquier IP pública
  ❌ Dominios externos

Beneficio:
  Seguridad mantenida + Funcionalidad local garantizada
